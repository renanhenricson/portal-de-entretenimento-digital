# 🎬🎧🎮 Meu Portal de Entretenimento Digital

Página web temática desenvolvida para a atividade **Agenda 13 – CSS**, utilizando **HTML5** e **CSS3**. O projeto funciona como um guia visual e direcionador de links para plataformas de filmes, séries, músicas, podcasts, games e tecnologia.

---

## 📋 Sobre o Projeto

O objetivo da página é reunir, em uma interface limpa e responsiva, atalhos visuais rápidos para conteúdos de cultura pop e entretenimento digital, divididos em três categorias principais:

* **Filmes e Séries:** Sugestões de lançamentos e direcionamento para plataformas de streaming e cinema.
* **Música e Podcasts:** Destaques de áudio com links diretos para serviços de streaming musical e programas.
* **Games e Tecnologia:** Novidades do universo gamer e tecnológico, encaminhando o visitante para portais da área.

---

## 🛠️ Tecnologias e Conceitos Aplicados

* **HTML5 Semântico:** Estruturação organizada com `<header>`, `<main>`, `<section>` e `<footer>`.
* **CSS Reset (Eric Meyer):** Padronização de margens e estilos padrão entre diferentes navegadores (`reset.css`).
* **Três tipos de CSS:**
  * **Externo (`style.css`):** Responsável pelo layout principal, cards, tipografia e responsividade.
  * **Interno (`<style>`):** Aplicado no `<head>` para estilização exclusiva do cabeçalho.
  * **Inline (`style="..."`):** Utilizado diretamente na tag `<footer>`.
* **Flexbox:** Alinhamento das três seções lado a lado em telas maiores e empilhamento responsivo em dispositivos móveis.
* **Interatividade com `:hover`:** Efeito suave de zoom (`transform: scale`) e transição nas imagens clicáveis.
